# Declaracion de Uso de Inteligencia Artificial

Durante el desarrollo de este reto se utilizo asistencia de inteligencia artificial para:

- entender el enunciado del reto;
- proponer la arquitectura inicial;
- generar una primera version del codigo;
- redactar documentacion tecnica;
- preparar explicaciones para la defensa.

La responsabilidad de revisar, ejecutar, probar y defender la solucion corresponde al candidato.
